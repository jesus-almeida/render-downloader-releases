# Render Downloader - instaladores

Aqui se publican las versiones de **Render Downloader**, el descargador de videos del equipo de Render.

- Descarga la ultima version en **Releases** (archivo `RenderDownloader-Setup.exe`).
- Si ya tienes la app instalada, no hace falta entrar aqui: la app avisa sola cuando hay una version nueva.

Este repositorio solo contiene instaladores; el codigo fuente es privado.
